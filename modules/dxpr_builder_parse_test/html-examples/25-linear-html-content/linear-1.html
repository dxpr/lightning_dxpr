The our CMS Security Team has released critical security updates addressing several vulnerabilities discovered in recent versions. All site administrators are strongly encouraged to update their installations immediately.

Security Advisory Details

This security release addresses multiple vulnerabilities including potential cross-site scripting (XSS) vectors and access bypass issues. The vulnerabilities range from moderately critical to highly critical, affecting various components of the our CMS core.

Affected Versions

The security updates are available for all supported our CMS versions. Sites running older versions should prioritize updating to the latest stable release to ensure maximum security protection.

Immediate Action Required

Site administrators should plan for immediate updates, especially for production sites handling sensitive data or user information. The security team recommends testing updates in staging environments before applying to production systems.

Update Process

Updates can be applied through Composer, the standard method for managing our CMS installations. Detailed update instructions are available in the official security advisory documentation.

For sites using contributed modules, administrators should also check for corresponding security updates and ensure all components are running the latest secure versions.

Support Resources

The our CMS community provides extensive support resources for sites requiring assistance with the update process. Community forums, documentation, and professional services are available to ensure smooth security updates.
