Nested Grid with Specific Column Classes (.col-sm-3, .col-8)

Expected layout: On mobile: Full-width stacked columns, inner nested columns show 66.67% and 33.33% (col-8/col-4). On small screens+: Left column 25% width (col-sm-3), right column 75% width (col-sm-9), both inner nested columns are 50% each (col-sm-6).

Level 2: .col-8 .col-sm-6

Nested Grid with Row-Based Classes (.row-cols-*)

Expected layout: Identical responsive behavior to the previous example but using row-cols approach. On mobile: Full-width stacked outer columns, inner row creates 3 slots where col-2 takes 66.67% and col-1 takes 33.33%. On small screens+: Left column 25%, right column 75%, inner row creates 2 equal slots of 50% each.

Level 1: responsive with .col-sm-3
Level 2: .row-cols-3 .row-cols-sm-2 with .col-2
Level 2: .row-cols-3 .row-cols-sm-2 with .col-1
